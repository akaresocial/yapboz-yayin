# yapbozmobilya.com.tr — yayın dosyaları

Bu depo otomatik üretilir; elle değiştirmeyin. Yalnız sitede zaten herkese açık olan dosyaları içerir
(sayfalar, stil, görseller). Sunucu bu depodaki yeni sürümü birkaç dakika içinde kendisi çeker.
Kaynak dosyalar ve üretim betikleri ayrı, gizli bir depodadır.
